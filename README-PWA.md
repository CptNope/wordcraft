# WordCraft PWA (CptNope fork)

This fork adds an installable GitHub Pages PWA to the upstream Rust/WebAssembly WordCraft browser editor, with build-versioned offline app caching and a compact phone workspace.

## Deployment

1. In GitHub **Settings → Pages**, select **GitHub Actions** as the build source.
2. Push to main or manually run **Deploy WordCraft PWA to GitHub Pages** under Actions.
3. Open https://cptnope.github.io/wordcraft/ in a mobile browser and select **Install WordCraft**, or use the browser's Add to Home Screen menu.

The untouched starting point is preserved at `backup/original-fork-2026-10-18`.

The browser can download edited documents, and its UI preferences are saved locally. Offline caching stores the app code, NOT your documents. Save/export your work; a PWA is not a substitute for document backups. First launch requires internet; cache quotas may limit offline functionality for large WASM builds.

The icon generated by this fork is a generic original document motif, not an imitation of Microsoft or ArtCraft marks. Preserve the upstream license and attribution notices.
